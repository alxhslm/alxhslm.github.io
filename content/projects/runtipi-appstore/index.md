I've been setting up a homelab using [Runtipi](https://runtipi.io/). This is a self-hosted app platform which makes it easy to spin up containerised services using Docker Compose. The UI is simple and I'm already comfortable with containers, so it was a natural fit.

One of the best features is that you can create your own custom app store to host apps that aren't in the official catalogue. I put together my own store for a handful of apps I couldn't find elsewhere. I've focussed mostly on apps which make my homelab play nicely with the Apple ecosystem so far.
